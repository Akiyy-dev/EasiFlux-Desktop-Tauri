# Phase 1D: 声明式插件命令

日期：2026-09-15。基线：`main@02380a4`。分支：`plugin/declarative-commands`。

## 目标与方案

用户已同意实现上一轮提出的受控贡献与示例插件闭环，并要求自主推进、减少重复测试。本阶段交付：导入示例清单，显式启用后出现命令按钮，点击由宿主展示插件提供的只读文本，停用后按钮与结果均撤销。

比较三个落点：任意脚本执行需要独立沙箱设计；页面导航涉及尚未交付的全局命令系统和业务模块生命周期；固定的只读信息动作只依赖已有插件目录。本阶段采用第三种，不新增全局快捷键、路由、后台执行或 IPC。命令仅在插件的已安装/管理卡片中提供，不在市场中执行。

## 清单兼容性

- v1 保持原样：`schemaVersion: 1`，`contributions: []`，`requestedCapabilities: []`。
- v2 使用相同顶层字段，`schemaVersion: 2`，仅允许本地声明式来源；内置目录继续只接受 v1 且生产目录保持为空。
- v2 的 contributions 必须有 1–16 项。每项严格为：

```json
{
  "kind": "command",
  "contributionId": "guide.overview",
  "title": "查看使用指南",
  "actionId": "host.showInfo",
  "params": {
    "title": "工作区使用指南",
    "text": "这是插件作者提供的只读说明。"
  }
}
```

- contributionId 使用现有 PluginId 的小写反向域名语法（128 字节总长、63 字节每段），在插件内唯一。不同插件可使用相同 contributionId，执行身份始终是插件 ID 加贡献 ID。
- 命令 title 和 params.title 各为非空普通文本，最多 80 UTF-8 字节；params.text 最多 2000 UTF-8 字节且非空。空白判断与现有 manifest 保持一致，包含 U+FEFF。
- 所有对象层级必须是对象，不接受 positional array、重复字段、未知字段、未知 kind/actionId。仅 `host.showInfo`，不能提供 URL、路径、IPC 名、HTML 模板或能力参数。
- requestedCapabilities 和 grantedCapabilities 继续为空；不新增依赖，不改变已有磁盘预算。
- Rust 引入准确命名的通用 PluginManifest，保留 PluginManifestV1 类型别名供已有内部调用兼容，新增代码使用通用名。贡献使用强类型对象。TypeScript 保留严格 v1 类型并引入 v2 联合类型。

## 授权连续性与安全边界

本地授权仍绑定已有完整规范化清单 SHA-256。保持 v1 的规范化字节和摘要格式不变；v2 的 schema、所有命令 ID、标题、动作和参数都进入规范化内容。对象字段顺序不改变摘要，任何语义变化导致旧启用决定不再匹配。继续沿用已有 `v1:sha256:` 指纹格式版本（不是清单版本），不迁移状态或所有权格式。

v2 不允许作为 builtIn 记录，避免沿用内置 v1:none 授权。未来内置真实贡献必须另行设计指纹兼容性。

此动作是宿主 UI 的纯文本渲染，不需要新的 Rust 执行端点；后端负责清单/状态真实性，前端仅从已确认目录派生可执行按钮。没有插件回调、自动运行、eval、v-html、链接跳转、动态 IPC 或商业数据访问。

## 前端生命周期

- 使用现有 plugin store 单一目录，不维护可独立存活的第二份插件注册表。
- 仅确认目录处于 available/ready、没有加载/重扫失败或进行中、没有导入/移除操作进行中或结果未知、没有未确认启停状态，且当前插件为 localDeclarative、enabled、可切换、无移除锁时提供命令。
- 命令列表和已展示信息必须由当前插件身份/目录 generation 与 revision 约束。停用、删除、内容变化、目录失效、开始重扫、启停等待、离开页面后撤销显示；重新变为可用不能自动恢复旧结果，必须重新点击。
- 保守处理未知结果：启停请求异常后也关闭命令，直到一次完整目录重新确认；不要仅因为 catch 清空 pending 就恢复旧的 enabled 授权。
- 同步点击执行前再次检查 gate 和该插件/贡献是否仍存在，返回宿主拥有的只读信息模型或无结果。渲染文案只使用 Vue 文本插值；清晰显示插件名称和“插件提供的信息，未经认证”。
- 展示可访问的普通按钮和信息区域、关闭按钮、aria-live；不创建第二个模态窗口或复杂焦点管理。
- 导入预览列出命令名称和只读动作范围，提示导入后默认停用。v1 仍明确“只记录偏好”；v2 提示启用后提供只读命令且不运行插件代码。

## 示例与验收

在 `examples/plugins/workspace-guide/manifest.json` 提供明确标注的示例，不自动导入或伪装生产内置插件。两个只读命令展示“插件使用流程”和“安全边界”，不包含金融建议。

验收覆盖：v1 兼容、v2 严格校验、内容身份绑定、导入默认停用；前端 service 解析与 store 保留贡献；启用→点击展示→停用撤销；未确认状态禁止执行；HTML 仅显示为文本；重复贡献 ID 只能在不同插件间重用。

只运行针对新增边界的 Rust/Vitest 测试和最终前端类型/构建检查，不反复跑整应用测试或原生 UI。既有 OS 5 未复现且未修复，维持已接受的风险记录，不在此阶段修改文件删除/提升算法。
