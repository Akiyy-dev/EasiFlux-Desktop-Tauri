# 工作区指南：手动导入示例

这是 Manifest v2 示例，不是生产内置插件，不会自动安装或启用。

1. 打开 EasiFlux 的“已安装插件”或“插件管理”，点击“导入本地清单”。
2. 选择本目录的 `manifest.json`，核对预览中的作者、名称及两个只读命令，再确认导入。
3. 导入后默认停用。明确启用后，点击“查看插件使用流程”或“查看安全边界”。
4. 停用插件，确认命令与已显示信息消失；再次启用不会自动恢复旧信息，需要重新点击。
5. 如需移除，先停用，再移除 EasiFlux 管理的副本；本目录的源文件不受影响。

两个命令只让宿主展示普通文本，不运行代码、不联网、不导航、不读取业务数据、不申请权限。作者信息及输出未经认证。市场页面不执行命令。

操作结果未知、加载或重扫失败时命令关闭；请重新扫描确认状态。修改清单内容会改变启用身份，不能沿用旧内容的授权。导入不支持覆盖相同 ID；本示例仅用于体验现有流程，不提供插件 SDK。

详细格式与历史安全约束见 [本地清单文档](../../../docs/plugin-local-manifests.md)。
