# 工作区指南：手动导入示例

这是 Manifest v2 示例，不是生产内置插件，不会自动安装或启用。

1. 打开 EasiFlux 的“已安装插件”或“插件管理”，点击“导入本地清单”。
2. 选择本目录的 `manifest.json`，核对预览中的作者、名称及两个只读命令，再确认导入。
3. 导入后默认停用。明确启用后，可以直接点击卡片中的“查看插件使用流程”或“查看安全边界”。
4. 也可以留在“已安装插件”，切换到“命令工作台”，再按命令名称、贡献 ID、插件名称或插件 ID 搜索这两个命令。搜索忽略首尾空白和大小写；点击带有本插件名称与 ID 的“显示信息”按钮才会显示内容。
5. 更改工作台搜索、关闭结果、切换视图或分区都会撤销已显示的信息。停用插件、加载或重扫、目录内容变化及结果未知也会撤销命令和信息；再次启用或恢复可用不会自动恢复旧结果，需要重新点击。
6. 如需移除，先停用，再移除 EasiFlux 管理的副本；本目录的源文件不受影响。

两个命令只让宿主展示普通文本，不运行代码、不联网、不导航、不读取业务数据、不申请权限。作者信息及输出未经认证，HTML、Markdown 与 URL 都不会被解释或激活。市场页面不执行命令；命令工作台也不是全局命令面板或在线插件市场，不提供全局快捷键、下载、历史或收藏。

操作结果未知、加载或重扫失败时命令关闭；请重新扫描确认状态。修改清单内容会改变启用身份，不能沿用旧内容的授权。导入不支持覆盖相同 ID；本示例仅用于体验现有流程，不提供插件 SDK。

详细格式与历史安全约束见 [本地清单文档](../../../docs/plugin-local-manifests.md)。
